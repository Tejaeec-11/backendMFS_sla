         THEORY QUESTIONS

         1. What is a Promise?
         A Promise represents the future result of an asynchronous operation.

         2. What are the three Promise states?
         Three Promise states: Pending, Fulfilled, Rejected.

         3. What is the difference between resolve and reject?
         resolve means success; reject means failure.

         4. What is .then()?
         .then() handles a successful Promise result.

         5. What is .catch()?
         .catch() handles a rejected Promise or an error.

         6. What is .finally()?
         .finally() executes whether the Promise succeeds or fails.

         7. What is fetch()?
         fetch() is used to request data from an API.

         8. Why do we use response.json()?
         response.json() converts the response body into JavaScript data.

         9. What is async?
         async makes a function return a Promise.

         10. What is await?
         await waits for a Promise to settle inside an async function.

         11. What is the difference between .then() and await? 
         .then() uses callbacks; await allows code to be written
         in a style that looks more like synchronous code.

         12. Does fetch reject for 404?
         fetch() does not reject automatically for HTTP 404.
         Use response.ok to check HTTP errors.
